# ملفات البوستر العامة

هذه ملفات رسومية بلا صور أو أسماء أو سجلات أشخاص. لا توجد مجموعة اختبار مصرح بها في مساحة التسليم، لذلك كل metric أدناه غير مقاس، والرسوم المؤقتة موسومة **في انتظار بيانات الاختبار**. لا تعدّل القيم إلى أرقام تقديرية.

بعد تشغيل `face-memory-evaluate` داخل `reports/private/`، راجع CSV وSVG الناتجة. احذف أي معرف أو تفصيل قد يعرّف المشارك قبل نقل نتائج مجهولة إلى هذا المجلد. تُحوّل مصفوفة الالتباس معرّفات الهويات إلى `ID-01`, `ID-02`، وتبقي فئة الغرباء `Unknown`.

- `poster_report.json`: حالة القياس والحجم/الإعدادات المتاحة.
- `poster_metrics.csv`: القيم والحالة والهدف وحجم العينة.
- `confusion_matrix.svg`: قالب مصفوفة الالتباس المؤقت.
- `accuracy_fpir_threshold.svg`: قالب منحنى validation المؤقت.
- `system_flow.svg`: رسم مسار النظام المحلي وPi.
- `screenshots/`: مجلد اختياري لحفظ لقطات الواجهة بعد مراجعتها؛ لا توجد لقطات ضمن القوالب الحالية.
