# إعداد نشر لاحق على Vercel

هذه تعليمات تجهيز فقط؛ لا يوجد نشر حي في هذه المرحلة. واجهات Next.js تعمل كـNode handlers مع MongoDB، أما خدمة الصور وWhisper فيجب تشغيلهما على خدمة Python منفصلة يمكن لـVercel الوصول إليها.

اضبط متغيرات بيئة Vercel لكل بيئة بعد توفير MongoDB Atlas وخدمة Python:

| المتغير | القيمة |
|---|---|
| `MONGODB_URI` | URI لـAtlas، كسر في إعدادات Vercel لا في Git |
| `MONGODB_DB` | `dementia_face_memory` |
| `SESSION_SECRET` | قيمة عشوائية طويلة وفريدة لبيئة الإنتاج |
| `MODEL_SERVICE_URL` | عنوان HTTPS لخدمة FastAPI |
| `MODEL_SERVICE_TOKEN` | رمز عشوائي طويل، مطابق داخل خدمة FastAPI |
| `DEVICE_SYNC_TOKEN` | رمز مستقل لأحداث الجهاز |

تتحقق خدمة FastAPI من `x-model-token` عندما يكون `MODEL_SERVICE_TOKEN` مضبوطًا. لا تضع `127.0.0.1` على Vercel؛ العنوان المحلي يصلح للتطوير فقط. استخدم TLS وحدًّا لحجم الطلبات، ولا تشغّل خدمة التعرف بلا مصادقة عند ربطها بعنوان عام.

بعد نقل قاعدة البيانات، تحقق من حسابين مختلفين، وحدود استدعاء الموديل، وسجلات الصوت والصور، ثم اختبر الخدمة على عينة مصرح بها. لا تنفّذ نشرًا إنتاجيًا قبل إعداد Atlas والخدمات واختبارها.
